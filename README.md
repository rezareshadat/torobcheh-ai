# تربچه AI | Torobcheh

**دستیار شخصی انتخاب و مقایسه کالا و خدمات**  
نمونه اولیه مستقل برای چالش استخدامی AI Product Engineer ترب.

> وضعیت: دموی تعاملی رابط کاربری (Proof of Concept). این نسخه به LLM یا فروشگاه‌های واقعی متصل نیست.

## اجرای سریع

فایل `index.html` را در مرورگر باز کنید. نیاز به نصب، حساب کاربری، API key یا اینترنت ندارد.

## ویژگی‌های قابل آزمایش

- مکالمه و جست‌وجوی فارسی با نمونه‌های ازپیش‌تعریف‌شده
- دو پروفایل فرضی با ترجیحات متفاوت و تغییر رتبه‌بندی
- اولویت درخواست فعلی کاربر نسبت به ترجیحات تاریخی
- روشن و خاموش کردن شخصی‌سازی
- مدیریت آزمایشی حافظه در نشست جاری
- توضیح «چرا این گزینه؟» و مقایسه پیشنهادها
- سناریوهای نمونه در لپ‌تاپ، خانه و آموزش
- طراحی Responsive و راست‌به‌چپ

## سناریوی ارزیابی

1. نیاز به لپ‌تاپ با بودجه محدود را جست‌وجو کنید.
2. بین دو پروفایل فرضی جابه‌جا شوید و تغییر رتبه‌بندی را بررسی کنید.
3. نیاز جدید («این بار برای گیم») را وارد کنید؛ درخواست صریح باید مقدم باشد.
4. حافظه را غیرفعال کنید و دوباره نتایج را ببینید.
5. دلایل یک پیشنهاد و جدول مقایسه را باز کنید.

## معماری نسخه فعلی

یک فایل HTML شامل CSS و JavaScript؛ اطلاعات نمونه داخل فایل تعریف شده‌اند. رتبه‌بندی قاعده‌محور و محلی است و **یادگیری واقعی از تاریخچه جست‌وجوی کاربران، خزش زنده بازار و فراخوانی LLM در این نسخه وجود ندارد.**

## مسیر پیشنهادی نسخه بعدی

1. اتصال به منابع داده مجاز و ثبت منشأ و تازگی قیمت و موجودی
2. استخراج نیاز، مشخصات و نرمال‌سازی داده با LLM و خروجی ساختاریافته
3. ذخیره ترجیحات با رضایت صریح، کنترل حذف و ویرایش
4. فیلتر محدودیت‌های قطعی و رتبه‌بندی قابل آزمون با توضیح مستند
5. اندازه‌گیری معیارهایی مثل دقت استخراج، کیفیت تطبیق، رعایت محدودیت‌ها و رضایت کاربر

## انتشار در GitHub Pages

یک مخزن **Public** جدید با نام `torobcheh-ai` بسازید. محتوای همین پوشه را **در ریشه مخزن** آپلود کنید، نه پوشه والد آن را. سپس به `Settings → Pages → Build and deployment` بروید و `Deploy from a branch`، شاخه `main` و پوشه `/ (root)` را انتخاب کنید. پس از فعال شدن Pages، لینک سایت به شکل زیر خواهد بود (نام کاربری را با نام واقعی خود جایگزین کنید):

## شفافیت و حریم خصوصی

- اطلاعات قیمت و محصولات آزمایشی هستند و نباید برای خرید واقعی استفاده شوند.
- حافظه این نمونه فقط در رابط جاری است و نمایانگر دسترسی به سوابق واقعی کاربر نیست.
- پروژه مستقل است و به‌عنوان محصول رسمی ترب معرفی نمی‌شود.
